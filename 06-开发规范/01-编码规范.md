# 编码规范

## 1. 概述

### 1.1 目的

统一团队编码风格，提高代码质量和可维护性。

### 1.2 适用范围

- TypeScript / JavaScript
- React组件
- Node.js服务端代码

---

## 2. 命名规范

### 2.1 文件命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 组件文件 | PascalCase | `UserProfile.tsx` |
| 工具文件 | camelCase | `dateUtils.ts` |
| 类型文件 | PascalCase + .types | `User.types.ts` |
| 测试文件 | 原文件名 + .test | `UserProfile.test.tsx` |
| 样式文件 | 原文件名 + .module | `UserProfile.module.css` |

### 2.2 变量命名

```typescript
// ✅ 正确
const userName = 'John';
const MAX_RETRY_COUNT = 3;
const isLoading = true;
const userList: User[] = [];

// ❌ 错误
const user_name = 'John';
const maxretrycount = 3;
const loading = true;
const list: User[] = [];
```

### 2.3 函数命名

```typescript
// ✅ 正确 - 动词开头
function getUserById(id: string): User {}
function calculateTotalPrice(items: Item[]): number {}
function isValidEmail(email: string): boolean {}
function formatDate(date: Date): string {}

// ❌ 错误
function user(id: string): User {}
function total(items: Item[]): number {}
function email(email: string): boolean {}
```

### 2.4 类型/接口命名

```typescript
// ✅ 正确 - PascalCase，名词
interface UserProfile {}
type UserRole = 'admin' | 'user';
class UserService {}

// ❌ 错误
interface userProfile {}
type userRole = 'admin' | 'user';
class userService {}
```

### 2.5 常量命名

```typescript
// ✅ 正确 - UPPER_SNAKE_CASE
const API_BASE_URL = 'https://api.example.com';
const MAX_FILE_SIZE = 10 * 1024 * 1024;
const DEFAULT_TIMEOUT = 30000;

// ❌ 错误
const apiBaseUrl = 'https://api.example.com';
const maxFileSize = 10 * 1024 * 1024;
```

## 3. 代码格式

### 3.1 缩进

```typescript
// ✅ 使用2个空格缩进
function example() {
  if (condition) {
    doSomething();
  }
}

// ❌ 使用Tab或4个空格
function example() {
    if (condition) {
        doSomething();
    }
}
```

### 3.2 行长度

```typescript
// ✅ 每行不超过100个字符
const result = someLongFunction(
  parameterOne,
  parameterTwo,
  parameterThree
);

// ❌ 超长行
const result = someLongFunction(parameterOne, parameterTwo, parameterThree, parameterFour, parameterFive);
```

### 3.3 花括号

```typescript
// ✅ 花括号在同一行
if (condition) {
  doSomething();
}

function example() {
  return true;
}

// ❌ 花括号在下一行
if (condition)
{
  doSomething();
}
```

### 3.4 空行

```typescript
// ✅ 函数之间空一行
function first() {
  // ...
}

function second() {
  // ✅ 逻辑块之间空一行
  doFirst();
  
  doSecond();
}

// ❌ 没有空行
function first() {
  // ...
}
function second() {
  doFirst();
  doSecond();
}
```

## 4. TypeScript规范

### 4.1 类型定义

```typescript
// ✅ 使用interface定义对象类型
interface User {
  id: string;
  name: string;
  email: string;
  age: number;
}

// ✅ 使用type定义联合类型或交叉类型
type Status = 'active' | 'inactive' | 'pending';
type UserWithRole = User & { role: string };

// ❌ 使用any
function processData(data: any): any {
  // ...
}

// ✅ 使用unknown代替any
function processData(data: unknown): unknown {
  // ...
}
```

### 4.2 泛型

```typescript
// ✅ 有意义的泛型名称
function getLastItem<T>(items: T[]): T | undefined {
  return items[items.length - 1];
}

interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

// ❌ 单字母泛型（除非是简单场景）
function getLastItem<I>(items: I[]): I | undefined {
  return items[items.length - 1];
}
```

### 4.3 类型断言

```typescript
// ✅ 使用as语法
const user = data as User;

// ❌ 使用尖括号语法（JSX中会冲突）
const user = <User>data;

// ✅ 非空断言
const element = document.getElementById('root')!;

// ⚠️ 谨慎使用非空断言，优先使用可选链
const length = data?.items?.length ?? 0;
```

### 4.4 枚举

```typescript
// ✅ 使用const enum（性能更好）
const enum Status {
  Active = 'active',
  Inactive = 'inactive'
}

// ✅ 或使用联合类型（更轻量）
type Status = 'active' | 'inactive';
```

## 5. 函数规范

### 5.1 函数长度

```typescript
// ✅ 函数不超过50行
function processUser(user: User): ProcessedUser {
  const validated = validateUser(user);
  const enriched = enrichUserData(validated);
  const formatted = formatUser(enriched);
  return formatted;
}

// ❌ 过长的函数
function processUser(user: User): ProcessedUser {
  // 100+ 行代码...
}
```

### 5.2 参数数量

```typescript
// ✅ 参数不超过4个
function createUser(name: string, email: string, age: number): User {
  // ...
}

// ❌ 参数过多
function createUser(
  name: string,
  email: string,
  age: number,
  address: string,
  phone: string,
  role: string
): User {
  // ...
}

// ✅ 使用选项对象
interface CreateUserOptions {
  name: string;
  email: string;
  age: number;
  address?: string;
  phone?: string;
  role?: string;
}

function createUser(options: CreateUserOptions): User {
  // ...
}
```

### 5.3 返回值

```typescript
// ✅ 明确的返回类型
function getUser(id: string): User | null {
  // ...
}

// ❌ 隐式返回类型
function getUser(id: string) {
  // ...
}
```

## 6. 错误处理

### 6.1 异常处理

```typescript
// ✅ 使用try-catch处理可能的错误
async function fetchUser(id: string): Promise<User> {
  try {
    const response = await api.get(`/users/${id}`);
    return response.data;
  } catch (error) {
    logger.error(`Failed to fetch user: ${error.message}`);
    throw new UserNotFoundError(id);
  }
}

// ❌ 忽略错误
async function fetchUser(id: string): Promise<User> {
  const response = await api.get(`/users/${id}`);
  return response.data;
}
```

### 6.2 自定义错误

```typescript
// ✅ 定义具体的错误类型
class UserNotFoundError extends Error {
  constructor(userId: string) {
    super(`User not found: ${userId}`);
    this.name = 'UserNotFoundError';
  }
}

class ValidationError extends Error {
  constructor(
    public field: string,
    public value: unknown,
    message: string
  ) {
    super(message);
    this.name = 'ValidationError';
  }
}
```

### 6.3 Promise处理

```typescript
// ✅ 使用async-await
async function loadData(): Promise<Data> {
  const user = await fetchUser(id);
  const posts = await fetchPosts(user.id);
  return { user, posts };
}

// ❌ 嵌套Promise
function loadData(): Promise<Data> {
  return fetchUser(id).then(user => {
    return fetchPosts(user.id).then(posts => {
      return { user, posts };
    });
  });
}
```

## 7. 注释规范

### 7.1 文件注释

```typescript
/**
 * @file 用户服务模块
 * @description 处理用户相关的业务逻辑
 * @author John Doe
 * @created 2026-06-02
 */
```

### 7.2 函数注释

```typescript
/**
 * 获取用户信息
 * 
 * @param id - 用户ID
 * @returns 用户信息，如果用户不存在返回null
 * @throws {UserNotFoundError} 用户不存在时抛出
 * 
 * @example
 * ```typescript
 * const user = await getUserById('123');
 * ```
 */
async function getUserById(id: string): Promise<User | null> {
  // ...
}
```

### 7.3 行内注释

```typescript
function calculateTotal(items: Item[]): number {
  // 计算所有商品的总价
  const total = items.reduce((sum, item) => {
    // 应用折扣
    const discountedPrice = item.price * (1 - item.discount);
    return sum + discountedPrice;
  }, 0);
  
  return total;
}
```

## 9. React规范

### 9.1 组件定义

```typescript
// ✅ 使用函数组件
interface UserCardProps {
  user: User;
  onClick: (user: User) => void;
}

export function UserCard({ user, onClick }: UserCardProps) {
  return (
    <div onClick={() => onClick(user)}>
      {user.name}
    </div>
  );
}

// ❌ 使用class组件（除非需要生命周期）
export class UserCard extends React.Component {
  // ...
}
```

### 9.2 Props定义

```typescript
// ✅ 使用interface定义Props
interface ButtonProps {
  label: string;
  onClick: () => void;
  disabled?: boolean;
  variant?: 'primary' | 'secondary';
}

// ✅ 使用type定义复杂Props
type ListProps = {
  items: Item[];
  renderItem: (item: Item) => React.ReactNode;
} & React.HTMLAttributes<HTMLDivElement>;
```

### 9.3 Hook使用

```typescript
// ✅ 自定义Hook以use开头
function useUser(userId: string) {
  const [user, setUser] = useState<User | null>(null);
  const [loading, setLoading] = useState(true);
  
  useEffect(() => {
    fetchUser(userId).then(setUser).finally(() => setLoading(false));
  }, [userId]);
  
  return { user, loading };
}

// ✅ 使用
function UserProfile({ userId }: { userId: string }) {
  const { user, loading } = useUser(userId);
  // ...
}
```
