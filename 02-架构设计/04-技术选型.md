### 4.3 AI服务封装

```typescript
class AIService {
  private provider: AIProvider;
  private model: string;
  private maxRetries: number;
  private timeout: number;
  
  async chat(messages: Message[], options?: ChatOptions): Promise<string> {
    const config = {
      model: this.model,
      messages,
      temperature: options?.temperature ?? 0.7,
      max_tokens: options?.maxTokens ?? 4096,
      stream: options?.stream ?? false
    };
    
    return await this.withRetry(() => this.provider.chat(config));
  }
  
  async chatWithJSON<T>(messages: Message[], schema: JSONSchema): Promise<T> {
    const response = await this.chat(messages, { temperature: 0.1 });
    return this.parseJSON<T>(response, schema);
  }
  
  private async withRetry<T>(fn: () => Promise<T>): Promise<T> {
    for (let i = 0; i < this.maxRetries; i++) {
      try {
        return await fn();
      } catch (error) {
        if (i === this.maxRetries - 1) throw error;
        await this.delay(Math.pow(2, i) * 1000);
      }
    }
    throw new Error('Max retries exceeded');
  }
}
```

## 8. 版本管理

### 8.1 版本号规范

```
主版本号.次版本号.修订号
  │         │        │
  │         │        └── Bug修复、小改动
  │         └─────────── 新功能、向后兼容
  └───────────────────── 重大变更、不兼容
```

### 8.2 依赖版本策略

| 类型 | 策略 | 示例 |
|------|------|------|
| **核心框架** | 锁定主版本 | `react: "^19.0.0"` |
| **工具库** | 允许次版本更新 | `dayjs: "^1.11.0"` |
| **开发工具** | 允许修订号更新 | `eslint: "^9.0.0"` |
