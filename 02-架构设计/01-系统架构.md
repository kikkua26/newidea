### 2.2 应用层 (Application Layer)

**职责**: 业务流程编排和Agent协调

**核心组件**:

#### 2.2.1 Agent编排引擎 (Orchestrator)

```typescript
class Orchestrator {
  private taskScheduler: TaskScheduler;
  private stateManager: StateManager;
  private flowController: FlowController;
  private agentPool: AgentPool;
  private sharedContext: SharedContext;
  
  // 执行完整的标书生成流程
  async executeBidGeneration(request: BidGenerationRequest): Promise<void> {
    // 1. 解析招标文件
    const analysis = await this.agentPool.analyst.analyze(request.tenderDoc);
    
    // 2. 生成大纲
    const outline = await this.agentPool.outliner.generate(analysis);
    
    // 3. 生成正文（分组串行+跨组并发）
    const content = await this.generateContent(outline);
    
    // 4. 审核润色
    const finalContent = await this.reviewAndPolish(content);
    
    // 5. 导出
    await this.export(finalContent, request.exportConfig);
  }
  
  // 分组串行+跨组并发生成正文
  private async generateContent(outline: Outline): Promise<Content> {
    const groups = this.groupChapters(outline);
    
    // 跨组并发
    const results = await Promise.all(
      groups.map(group => this.generateGroupSerial(group))
    );
    
    return this.mergeResults(results);
  }
  
  // 组内串行生成
  private async generateGroupSerial(group: ChapterGroup): Promise<Content> {
    let result = '';
    
    for (const chapter of group.chapters) {
      // 获取共享上下文
      const context = this.sharedContext.getContextForChapter(chapter);
      
      // 生成内容
      const content = await this.agentPool.writer.write(chapter, context);
      
      // 更新共享上下文
      await this.sharedContext.updateAfterChapter(chapter, content);
      
      result += content;
    }
    
    return result;
  }
}
```

#### 2.2.2 任务调度器 (TaskScheduler)

```typescript
class TaskScheduler {
  private queue: PriorityQueue<Task>;
  private workers: Map<string, Worker>;
  private maxConcurrency: number;
  
  // 提交任务
  async submit(task: Task): Promise<TaskResult> {
    this.queue.enqueue(task, task.priority);
    return this.waitForCompletion(task.id);
  }
  
  // 执行任务
  private async execute(task: Task): Promise<TaskResult> {
    const worker = await this.acquireWorker();
    
    try {
      const result = await worker.execute(task);
      return result;
    } finally {
      this.releaseWorker(worker);
    }
  }
  
  // 支持任务暂停和恢复
  async pause(taskId: string): Promise<void>;
  async resume(taskId: string): Promise<void>;
  async cancel(taskId: string): Promise<void>;
}
```

#### 2.2.3 状态管理器 (StateManager)

```typescript
class StateManager {
  private states: Map<string, TaskState>;
  private persistence: StatePersistence;
  
  // 保存状态
  async saveState(taskId: string, state: TaskState): Promise<void> {
    this.states.set(taskId, state);
    await this.persistence.save(taskId, state);
  }
  
  // 恢复状态
  async restoreState(taskId: string): Promise<TaskState | null> {
    const state = this.states.get(taskId);
    if (!state) {
      return await this.persistence.load(taskId);
    }
    return state;
  }
  
  // 状态转换
  async transition(taskId: string, event: TaskEvent): Promise<TaskState> {
    const currentState = await this.getState(taskId);
    const nextState = this.calculateNextState(currentState, event);
    await this.saveState(taskId, nextState);
    return nextState;
  }
}
```

### 2.3 领域层 (Domain Layer)

**职责**: 核心业务逻辑和领域模型

**核心模型**:

interface Bid {
  id: string;

  id: string;

  order: number;

interface Agent {

## 4. 技术架构特点

### 4.1 模块化设计

- 各层职责清晰，低耦合高内聚
- 支持独立开发和测试
- 便于后续扩展和维护

### 4.2 事件驱动

- Agent间通过事件通信
- 支持异步处理
- 便于实现流式上下文传递

### 4.3 状态可恢复

- 所有中间状态持久化
- 支持任务暂停和恢复
- 支持断点续传

### 4.4 可观测性

- 完整的日志记录
- 性能指标监控
- 错误追踪和报警
