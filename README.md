## 🎯 项目概要

### 项目名称
AI智能编标系统 (AI Bid Writer)

### 项目目标
基于多Agent协作架构，实现高质量、高一致性的投标文件自动生成系统。

### 核心创新点
1. **多Agent协作** - 分析师、写手、审核员等角色协同工作
2. **共享上下文池** - 术语表、章节摘要、风格指南全局共享
3. **流式上下文传递** - 实时广播，边写边共享
4. **分组串行+跨组并发** - 平衡质量和效率
5. **多轮审核润色** - 确保输出质量

### 技术栈
- **前端**: React 19 + TypeScript + Vite
- **桌面端**: Electron 41+
- **后端**: Node.js + TypeScript
- **Agent框架**: 自研轻量级Agent框架
- **数据库**: SQLite + Redis
- **AI服务**: OpenAI兼容接口
